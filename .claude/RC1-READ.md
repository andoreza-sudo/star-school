# RC-1 (v188): new lines for the owner to read

Every new line a person sees or hears in v188. None is recorded audio: the tablet's voice says the spoken ones. Change any wording
here and tell Claude; nothing waits on this file to ship.

## Children see or hear

| Where | Line |
|---|---|
| Home, storage full (said aloud once) | Star School can't save right now: ask a grown-up to free some space. |
| Home, after a grown-up gave game time (said aloud once) | A grown-up gave you 10 minutes! (the number changes; "1 minute") |
| Picture password, title | Ben's secret pictures (the child's name) |
| Picture password, first line (said aloud) | Tap your 3 secret pictures. |
| Picture password, each picture (said on tap) | dog, star, apple, car, fish, sun, ball, tree, cake |
| Picture password, wrong (said aloud) | Not quite. Try again! |
| Picture password, after 5 wrong (said aloud) | Wait a minute, then try again. |
| Picture password, buttons | Grown-up help / Back |

## Grown-ups see

| Where | Line |
|---|---|
| PIN pad, first time (after the times-table question) | Choose a Grown-ups PIN / Pick 4 numbers. The PIN keeps children out of the settings. |
| PIN pad, again | Type it again / Type the same 4 numbers again. |
| PIN pad, mismatch | They didn't match. Choose a PIN again. |
| PIN pad | Grown-ups PIN / Type your 4-digit PIN. |
| PIN pad, wrong | That's not the PIN. Try again. |
| PIN pad, wait | Too many wrong PINs. Try again in 1 minute, or tap Forgot PIN? |
| PIN pad, buttons | Forgot PIN? / Cancel (keys read as "one" ... "zero", "Delete") |
| PIN saved / not saved (toasts) | PIN saved / The PIN could not be saved: the tablet's storage is full. |
| Change PIN | Your PIN now / New PIN / Pick 4 new numbers. |
| Forgot PIN? | Forgot PIN? / Answer all three to choose a new PIN. All progress is kept. / Check / Cancel |
| Forgot PIN?, wrong | Not quite. You can try again in 15 minutes. |
| Forgot PIN?, during the wait | Not yet. Try again in 15 minutes. / OK |
| Forgot PIN?, passed | Choose a new PIN / Pick 4 numbers. Use them next time. |
| Grown-ups, PIN card | Grown-ups PIN / The PIN keeps children out of the settings. / Change PIN |
| Grown-ups, About | To open Grown-ups, tap Grown-ups on Home and type your PIN. Forgot it? Tap Forgot PIN? on the number pad. |
| The first-time question (was "Hold the Grown-ups button for 3 seconds, or answer:") | This part is for grown-ups. Answer to go on: |
| Grown-ups, Backup card, after an erase | Undo erase / Erased by mistake? This brings back Mia's progress. You can undo it until Star School is opened again. |
| Delete a child, second step | You can undo it in Grown-ups until Star School is opened again. (was: This cannot be undone.) |
| Grown-ups, Game time | Give game time: +5 min, +10 min, +15 min / Take away: −5 min / Given time goes straight into the bank. It does not count as learning, and the daily max still applies. |
| Game time toasts | Gave 10 min of game time / Took away 5 min / The bank is already empty |
| Report card, a week with given time | Game time from a grown-up this week: +10 min (not learning time). |
| Grown-ups, Children card | Picture passwords / So children cannot play as each other, each child can have 3 secret pictures. Set them up here. / Each child opens with their 3 secret pictures. / Mia: on / Set up / Change / Turn off |
| Setting a child's pictures | Pictures for Mia / Pick 3 pictures in order. Show Mia which ones. / Save / Start again / Cancel |
| Grown-up help (after the PIN) | Help for Mia / Open Mia now / Show the pictures / In this order: / Turn the picture password off / Cancel |
| Picture password toasts | Picture password on for Mia / Picture password off for Mia / It could not be saved: the tablet's storage is full. |
